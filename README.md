# SharedSpace

Sistema web para monitoramento da ocupação de espaços compartilhados em ambientes corporativos.

## Objetivo

O SharedSpace permite consultar a ocupação de espaços compartilhados e auxilia os usuários a verificarem a disponibilidade antes de se deslocarem até o local.

## Status

Em desenvolvimento.
